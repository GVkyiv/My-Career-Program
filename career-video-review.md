# Анализ видео/статьи про рынок труда, Upwork, зарплаты, визы

## Назначение

Пользователь периодически присылает ссылки на видео, статьи или посты про
поиск работы, фриланс на Upwork, зарплатные обзоры, визовые вопросы
Ирландии или рынок труда Украины. Использовать этот промпт для КАЖДОГО
такого разбора — без исключений, чтобы не переписывать инструкцию заново.
Автоматически запускать, когда пользователь присылает такую ссылку с
пометкой вроде "что думаешь про это" — не дожидаться явного вызова файла.

---

Общая методология оценки достоверности источника, шкала вердиктов и
признаки дезинформации — в скиле `fact-checker` (`.claude/skills/`). Ниже
— специфика тематики поиска работы и фриланса поверх той методологии.

## Порядок работы: извлечение, слепая проверка, сборка

Порядок принципиален. Если проверять цифры в том же проходе, где уже
написано резюме, проверка идёт внутри рамки автора и превращается в
поиск подтверждений тому, во что модель уже поверила.

**Этап 1. Извлечение.** Из транскрипта или статьи выписывается список
атомарных проверяемых утверждений: ставки, проценты комиссии, зарплатные
цифры, визовые требования, статистика рынка. Без вердиктов и без резюме.

**Этап 2. Слепая проверка.** На каждое утверждение вызывается сабагент
`claim-verifier` (`.claude/agents/claim-verifier.md`), по одному вызову
на утверждение. Ему передаётся **только текст утверждения**: без имени
автора, без названия канала, без резюме, без остальных утверждений. Он
не знает, продаёт ли автор курс по фрилансу или коуч-программу.

**Этап 3. Сборка.** В основном контексте собирается итог: резюме,
таблица вердиктов, применимость к текущему направлению поиска (раздел
ниже). Резюме пишется здесь, последним, а не первым.

**Правило доказательства.** Вердикт "подтверждено" принимается только с
URL и дословной цитатой из источника. Нет цитаты, значит "не проверено".
Никаких цифр по памяти.

Пропорциональность: один верификатор на утверждение по умолчанию, второй
независимый — для всего, что может повлиять на решение сменить рынок,
ставку или визовую стратегию.

## Принципы анализа (обязательны все)

### 1. Скептицизм по умолчанию

Одно видео "как я заработал X на Upwork" — анекдотическое свидетельство,
не статистика. Каждое количественное утверждение (ставки, проценты,
сроки выхода на доход) — проверять через WebSearch на независимых
источниках (официальные страницы Upwork, государственная статистика
занятости, зарплатные обзоры с методологией), если это возможно. Если
проверить нельзя — явно помечать "непроверено, со слов автора".

### 2. Проверка автора/канала

- Независимый разбор или воронка продаж (курс "как выйти на Upwork",
  платный менторинг, реферальная ссылка на биржу/сервис)?
- Есть ли конфликт интересов: автор зарабатывает на продаже метода,
  который рекламирует?
- Утверждения подкреплены источниками/данными или голословны ("все
  зарабатывают по $50/час", "рынок сейчас такой" без ссылки)?

### 3. Явное разделение: факт / мнение автора / реклама

- ✅ **Проверяемый факт** — подтверждён независимым источником
- 🟡 **Мнение/прогноз автора** — правдоподобно, но не факт (особенно
  прогнозы про "рынок в 2027" или "скоро все будут работать так")
- 🔴 **Продажа/реклама** — призыв купить курс, подписаться на платный
  канал, перейти по реферальной ссылке

## Обязательная привязка к текущему направлению поиска

Прочитать перед анализом (не пересказывать видео в вакууме):

- `AGENTS.md` — какое направление сейчас в приоритете (Upwork → Ирландия
  → Украина)
- Соответствующий файл `01_markets/` (`upwork.md`, `ireland.md` или
  `ukraine.md`)

Для каждого значимого тезиса explicitly ответить:

- **Применимо к текущему направлению?** (тезис про американский рынок
  найма нерелевантен, если сейчас фокус на Upwork)
- **Уже учтено в `01_markets/`?**
- **Действие нужно?** Если да — какое, если нет — почему.

**ВАЖНО:** Одно видео никогда не является достаточным основанием для
смены направления поиска или переписывания `01_markets/` автоматически.
Genuinely actionable находки предлагать пользователю как пункт для
обсуждения, а не молча вносить изменение.
