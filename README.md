# My Career Program

Проект поиска работы и фриланса. Три направления в порядке приоритета:
Upwork (сейчас основной) → Ирландия → Украина.

Что делает агент и в каком порядке: `AGENTS.md`. Методология работы
(роль хедхантера, фазы цель → диагностика → сбор фактов → сборка →
критика): `01_process.md`.

## Структура

- `00_profile/candidate.md` — факты о кандидате, дисциплина
  verified-facts-only.
- `01_markets/` — позиционирование и требования под каждое направление
  (Upwork, Ирландия, Украина).
- `02_upwork/` — рабочие материалы фриланса: proposals, кейсы, ставка.
- `03_cv/current/` — актуальные резюме, `03_cv/archive/` — старые версии,
  только для истории.
- `gaps.md` — открытые вопросы и недостающие данные.

Стиль общения и коммуникационный профиль сюда не копируются, источник
правды — `Personal Core` (`core/identity.md`, `core/psychology.md`).

## Факт-чек внешнего контента

Если пользователь присылает видео или статью про рынок труда, Upwork,
зарплаты или визовые вопросы — разбор идёт по `career-video-review.md`:
резюме, факт-чек по каждому проверяемому утверждению через сабагента
`claim-verifier` (`.claude/agents/`), применимость лично к пользователю.
Общие критерии оценки источника — в скиле `fact-checker`
(`.claude/skills/`).

## Тесты

Кода здесь нет, только markdown, поэтому автотестов нет. Вместо них
дисциплина verified-facts-only (`01_process.md`, правило 4): ни одна
метрика, достижение или цифра не попадает в резюме/proposal без явного
подтверждения пользователем, пробелы помечаются `[НУЖНЫ ДАННЫЕ: ...]`, а
не выдумываются. Проверка — это сверка готового документа с исходными
фактами перед отправкой, вручную.
